Image Manipulation

An automatic slideshow, a gallery whose thumbnails open full size, and hover effects. The core of each is pure HTML and CSS.

  • Auto slideshow in HTML & CSS
  • Click-to-enlarge gallery
  • Smooth hover transitions

01 · Slideshow

Plays itself.

Five slides cross-fade every five seconds using CSS keyframe animations with staggered delays. Hover to pause.

02 · Gallery

Tap to enlarge.

Each thumbnail links to a full-size view. The CSS :target selector shows it, so no JavaScript is needed to open, close or move between images.

  • Fjord
  • Canyon
  • Highlands
  • Storm
  • Base camp
  • Waterfall
  • Valley
  • River
  • Coastline
  • Cliffs
  • Skyline
  • Alley

03 · Hover effects

Small moves, smooth feel.

Four transition styles. Hover over a card on desktop, or tap it on a touch screen.
